# 🕷️ Portofolio Alamsyah Khadir Ratuloly

Website portofolio single-page responsif modern dengan tema gelap (*creative dark mode*).

## 📁 Struktur Folder Proyek

```text
portfolio/
├── index.html              # File halaman utama website
├── style.css               # Styling CSS kustom (glassmorphism, animamsi, scrollbar)
├── script.js               # Logika JavaScript (typewriter, sticky nav, scrollspy)
├── foto-profil.jpg         # Foto diri Anda (Alamsyah Khadir Ratuloly)
├── animasi-spiderman.gif   # Animasi Spiderman bergelantungan
├── foto-sembako.jpg        # Screenshot project Web Toko Sembako Purnama
├── foto-ukm.jpg            # Screenshot project Web UKM Tapak Suci
└── README.md               # Dokumentasi panduan proyek
```

---

## 💻 Cara Membuka & Menjalankan di Visual Studio Code (VS Code)

1. Buka aplikasi **Visual Studio Code**.
2. Klik menu **File** > **Open Folder...** (atau tekan shortcut `Ctrl + K, Ctrl + O`).
3. Pilih folder:
   `c:\Users\USER\Documents\portfolio\`
4. Buka file **`index.html`**.
5. Untuk melihat tampilan website secara live:
   - **Cara 1 (Live Server - Direkomendasikan):** Klik kanan pada file `index.html` > pilih **Open with Live Server** (pastikan ekstensi *Live Server* oleh Ritwick Dey sudah terpasang).
   - **Cara 2 (Browser Langsung):** Klik kanan file `index.html` > pilih **Reveal in File Explorer** > klik ganda file `index.html` untuk membuka di Google Chrome atau Microsoft Edge.

## 🎨 Fitur Utama

- **Foto Profil Utama**: Menggunakan foto Anda (`foto-profil.jpg`) dengan frame *glass card* beraksen *neon red glow*.
- **Spiderman Swinging**: Animasi GIF Spiderman bergelantungan di sudut atas dengan efek ayunan CSS.
- **Typewriter Effect**: Efek teks mengetik otomatis untuk profesi dan keahlian Anda.
- **Sticky Navbar**: Navigasi bar yang menempel di bagian atas saat di-scroll dengan transisi blur dan menu mobile hamburger.
- **4 Kategori Skills**: Frontend, Backend, Database, serta Desain & Edit Video dengan logo SVG asli yang tajam.
- **Project Grid**: Menampilkan 4 project dengan efek hover glow interaktif.
- **Direct Social Links**: Menghubungkan pengunjung langsung ke Instagram, TikTok, WhatsApp, dan Gmail Anda di tab baru.
